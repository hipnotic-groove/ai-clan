# API сервера AI CLAN

Сервер ([script.js](script.js)) — один процесс на Node.js без фреймворков. Запуск: `npm start`, по умолчанию адрес `http://localhost:3000`.

У сервера два маршрута: страница сайта и чат с ИИ. Любой другой путь возвращает `404`.

| Метод | Путь | Назначение |
|-------|------|-----------|
| `GET` | `/` и `/index.html` | Страница сайта |
| `POST` | `/api/chat` | Вопрос ИИ-помощнику |

---

## `GET /` · `GET /index.html`

Возвращает страницу `index.html` (`Content-Type: text/html; charset=utf-8`).

- Сервер отдаёт **только** этот файл. Остальные файлы папки, включая `.env`, недоступны.
- В каждый тег `<script>` и `<style>` сервер подставляет одноразовый `nonce`, а в заголовке `Content-Security-Policy` разрешает только скрипты и стили с этим `nonce`.

---

## `POST /api/chat`

Принимает историю переписки и возвращает ответ ИИ. Сервер ничего не хранит между запросами: историю целиком присылает браузер.

### Запрос

Заголовок: `Content-Type: application/json`

```json
{
  "messages": [
    { "role": "user", "content": "Что такое нейросеть?" },
    { "role": "assistant", "content": "Это программа, которая учится на примерах..." },
    { "role": "user", "content": "А как начать её использовать?" }
  ]
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `messages` | массив | Непустой список сообщений, от старых к новым |
| `messages[].role` | строка | `"user"` (посетитель) или `"assistant"` (ИИ). Другие роли, включая `"system"`, отклоняются |
| `messages[].content` | строка | Непустой текст сообщения |

Что сервер делает с данными:

- берёт только последние **10** сообщений, более старые отбрасывает;
- обрезает каждое сообщение до **4000** символов;
- требует, чтобы последнее сообщение было от `user`;
- сам добавляет в начало системную инструкцию, браузер её не передаёт.

Размер всего тела запроса не больше **32 КБ**.

### Успешный ответ — `200`

```json
{ "reply": "Нейросеть — это ..." }
```

### Ошибки

Все ошибки приходят в виде `{ "error": "текст для посетителя" }`.

| Код | Когда | Текст `error` |
|-----|-------|---------------|
| `400` | Тело не является JSON | Некорректный JSON |
| `400` | `messages` не массив или пустой | Нужен непустой массив messages |
| `400` | Неверная роль или пустой текст | Некорректное сообщение в истории |
| `400` | Последнее сообщение не от `user` | Последнее сообщение должно быть от пользователя |
| `400` | Некорректный адрес запроса (например, `//`) | Некорректный адрес запроса |
| `405` | Метод не `POST` | Используй метод POST |
| `413` | Тело больше 32 КБ | Слишком длинный запрос |
| `429` | Больше 15 запросов в минуту с одного IP | Слишком много вопросов подряд. Передохни минутку. |
| `429` | OpenRouter перегружен | ИИ сейчас перегружен. Подожди немного и спроси снова. |
| `502` | Ошибка OpenRouter или пустой ответ модели | ИИ временно недоступен. Попробуй позже. / ИИ вернул пустой ответ. Попробуй переформулировать вопрос. |
| `504` | OpenRouter не ответил за 30 секунд | ИИ не ответил вовремя. Попробуй ещё раз. |
| `500` | Непредвиденный сбой сервера | Ошибка сервера |

Подробности ошибок OpenRouter пишутся только в консоль сервера, посетитель их не видит.

### Пример

```bash
curl -s localhost:3000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"messages":[{"role":"user","content":"Привет"}]}'
```

## Ограничения

| Параметр | Значение | Где в коде |
|----------|----------|-----------|
| Размер тела запроса | 32 КБ | `MAX_BODY_BYTES` |
| Сообщений в истории | 10 | `MAX_HISTORY` |
| Длина сообщения | 4000 символов | `MAX_MESSAGE_CHARS` |
| Частота запросов | 15 в минуту с одного IP | `RATE_LIMIT`, `RATE_WINDOW_MS` |
| Ожидание ответа OpenRouter | 30 секунд | `UPSTREAM_TIMEOUT_MS` |

Счётчик запросов хранится в памяти процесса и обнуляется при перезапуске. Если сервер стоит за обратным прокси, задайте `TRUST_PROXY`, иначе все посетители будут считаться одним IP.

## Настройка (переменные окружения)

Значения читаются из файла `.env` в корне проекта.

| Переменная | Обязательна | По умолчанию | Описание |
|------------|:-----------:|--------------|----------|
| `OPENROUTER_API_KEY` | да | — | Ключ API OpenRouter. Без него сервер не запустится |
| `OPENROUTER_MODEL` | нет | `nvidia/nemotron-3.5-lightning:free` | Модель, которая отвечает в чате |
| `PORT` | нет | `3000` | Порт сервера |
| `TRUST_PROXY` | нет | `0` | Число обратных прокси перед сервером. При значении больше 0 IP посетителя берётся из `X-Forwarded-For` |

## Заголовки безопасности

На всех ответах: `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, `Permissions-Policy` (камера, микрофон и геолокация отключены).

На странице дополнительно `Content-Security-Policy`: скрипты и стили только с `nonce`, шрифты Google Fonts, запросы только на тот же сервер, встраивание во фрейм запрещено.
