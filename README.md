## О проекте

AI CLAN — это лендинг сообщества людей, которые осваивают IT и используют нейросети как личный усилитель. Дизайн вдохновлён эстетикой Afterlife и Apple: глубокий чёрный фон, неоновые акценты, матовое стекло и плавные анимации.

Проект состоит из двух файлов: фронтенд в **`index.html`** (без сборщиков и фреймворков) и небольшой Node.js-сервер в **`script.js`**, который отдаёт страницу и пересылает вопросы из чата в нейросеть через OpenRouter.

## Возможности

- **Живой фон** — медленно дрейфующие неоновые пятна (оранжевое и фиолетовое) с сильным размытием, зерном и виньеткой.
- **Glassmorphism** — полупрозрачные карточки с `backdrop-filter: blur()` и тонкой светлой рамкой.
- **Градиентная типографика** — огромный заголовок с переливающимся градиентом от оранжевого к белому.
- **Неоновая кнопка** — свечение через `box-shadow`, плавное увеличение и смена цвета при наведении.
- **Кастомное модальное окно** — форма с email, проверкой ввода и экраном успеха (без стандартного `alert`).
- **Светящийся шлейф курсора** — отрисовывается на `<canvas>`, градиент от оранжевого к фиолетовому.
- **ИИ-чат** — посетитель задаёт вопрос прямо на странице, ответ генерирует нейросеть через OpenRouter.
- **Анимации появления** — при загрузке страницы и при скролле (`IntersectionObserver`).
- **Адаптивность** — корректно выглядит на телефонах, планшетах и десктопе.
- **Доступность** — управление с клавиатуры, закрытие окна по `Esc`, поддержка `prefers-reduced-motion`.

## Архитектура

```
Браузер (index.html)  ──POST /api/chat──▶  Сервер (script.js)  ──HTTPS──▶  OpenRouter
        ◀────── { reply } ──────────────────────◀──────────────────────────
```

### Фронтенд — `index.html`

Вся страница в одном файле: стили (`<style>`), разметка и скрипт (`<script>`), разбитый на независимые блоки — модальное окно, анимации при скролле, шлейф курсора и чат.

- Форма «Вступить» в модальном окне работает только на клиенте: email проверяется, но никуда не отправляется.
- Чат хранит историю переписки в браузере и при каждом вопросе отправляет серверу последние 10 сообщений.

### Бэкенд — `script.js`

Несмотря на название, это серверный файл, а не браузерный скрипт. Он обрабатывает два маршрута:

| Маршрут | Что делает |
|---------|-----------|
| `GET /` и `GET /index.html` | Отдаёт страницу. Других файлов сервер не отдаёт, поэтому `.env` недоступен из браузера |
| `POST /api/chat` | Принимает `{ "messages": [{ "role": "user", "content": "..." }] }`, добавляет системную инструкцию и возвращает `{ "reply": "..." }` или `{ "error": "..." }` |

Что делает сервер при обработке чата:

- проверяет историю: допустимы только роли `user` и `assistant`, последнее сообщение — от пользователя;
- ограничивает размер: запрос до 32 КБ, до 10 сообщений, до 4000 символов в каждом;
- ограничивает частоту: не более 15 запросов в минуту с одного IP (счётчик хранится в памяти);
- ждёт ответа OpenRouter не дольше 30 секунд;
- показывает посетителю только понятные сообщения об ошибках, а подробности пишет в консоль сервера.

Системная инструкция для модели (`SYSTEM_PROMPT`) задаёт роль помощника AI CLAN и язык ответов — русский.

## Запуск

Для чата нужен ключ [OpenRouter](https://openrouter.ai/keys) и Node.js 18 или новее.

**1. Установите зависимости**

```bash
git clone https://github.com/hipnotic-groove/ai-clan.git
cd ai-clan
npm install
```

**2. Создайте файл `.env`** в корне проекта:

```env
OPENROUTER_API_KEY=твой_ключ

# необязательно
PORT=3000
OPENROUTER_MODEL=nvidia/nemotron-3.5-lightning:free
```

| Переменная | Обязательна | По умолчанию | Назначение |
|------------|:-----------:|--------------|------------|
| `OPENROUTER_API_KEY` | да | — | Ключ API OpenRouter. Без него сервер сразу завершится с ошибкой |
| `OPENROUTER_MODEL` | нет | `nvidia/nemotron-3.5-lightning:free` | Модель, которая отвечает в чате |
| `PORT` | нет | `3000` | Порт сервера |

> Файл `.env` содержит секретный ключ и добавлен в `.gitignore`. Не коммитьте его и не публикуйте.

**3. Запустите сервер**

```bash
npm start
```

Откройте <http://localhost:3000>.

> Если открыть `index.html` двойным кликом или через `python3 -m http.server`, страница отобразится, но чат работать не будет — ему нужен запущенный `npm start`.

## Публикация

Из-за серверной части проект **нельзя** разместить на GitHub Pages целиком: там запускаются только статические файлы, а чату нужен Node.js-сервер с секретным ключом. Для публикации подойдёт любой хостинг с Node.js (Render, Railway, VPS и т. п.): задайте `OPENROUTER_API_KEY` в переменных окружения хостинга и используйте команду запуска `npm start`.
